# 街角早餐铺

一个关于“被记住的那一口”的中文早餐经营小游戏。你经营一家街角小店，为有不同口味和故事的街坊做早餐。

> **开发状态：测试原型开发中，当前尚不可玩。** 本目录已准备规则层和本地服务器；界面、流程测试和完整试玩仍待实现。远端私有仓库由开发侧建立和同步，未确认远端完成前暂停后续游戏实现。不要把本仓库当前状态当作已发布产品。

## 核心体验（原型目标）

- 三道明确配方：招牌煎饼、芝士蛋饼、香煎饭团。
- 五个短关卡：第一缕香气、街坊的口味、早高峰不慌、雨天也温暖、这条街的早安。
- 顾客会说“不吃葱”“赶时间”“想吃脆的”，同时展示明确的口味、火候和装盘要求，不惩罚玩家对模糊语义的猜测。
- 实际操作：选取食材 → 选择火候 → 加热 → 堂食或打包 → 出餐；失误后可清空重做。
- 回头客对白、街景小变化和暖心关卡故事让经营有记忆点。对白是本地编写的规则内容，不使用运行时生成式 AI。
- 手机竖屏触控与桌面鼠标操作；无需拖拽、无强制倒计时。
- 关卡解锁、星级、最佳成绩与音效偏好使用浏览器本地保存。
- 原创 CSS / SVG 插画，无购买素材、第三方素材下载或运行时付费服务。

## 本地开发

需要 Node.js 20 或更新版本。项目不依赖第三方运行库，也不需要 `npm install`。

```sh
npm run serve
```

完成界面实现后，访问 `http://localhost:4173`。当前若首页尚未建立，返回 404 是预期的开发中状态。可用 `PORT=4174 npm run serve` 更改端口。

```sh
npm test
npm run check
```

**当前测试尚未编写，`npm test` 暂时不能作为测试完成证据；`npm run check` 在 app.js 建立前不能通过。** 完成后会更新本节并提交真实测试结果。

## 工程结构

- `game.js`：可独立测试的配方、顾客、关卡、评分和状态机。
- `server.mjs`：仅用于本地测试的静态文件服务器。
- `index.html`、`style.css`、`app.js`：待实现的自适应界面与输入、音效、存档适配。
- `tests/`：待实现的 Node 内建测试。
- `TEST_PLAN.md`：规则与端到端流程测试清单。
